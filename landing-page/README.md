# Software Developer Landing Page

Landing page profissional desenvolvida para apresentar meu perfil como desenvolvedor de software Full Stack, com foco em sistemas corporativos, ERP, integrações, dados, relatórios e APIs.

O projeto reúne informações sobre minha experiência, principais tecnologias, áreas de atuação, projetos em destaque e canais de contato profissional.

## Tecnologias

- PHP 
    - Codeigniter 
    - Laravel
- HTML5
- CSS3
- JavaScript 
    -jQuery
- Worker ESM
- Design responsivo

## Objetivo

Criar uma página simples, moderna e responsiva para servir como portfólio profissional, reforçando minha atuação em desenvolvimento de software, integrações entre sistemas, análise de dados e soluções para ambientes corporativos.
