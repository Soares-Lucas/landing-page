Lumus Data Engine

Arquitetura de Engenharia

Visão Geral

Motor de relatórios com Python e Docker, exportação em CSV, Excel e (futuramente) PDF, integrado a sistemas PHP.

Fluxo Arquitetural
OrigemPHP / Monolito
ProcessamentoPython Engine (Docker)
DestinoExport CSV / XLSX / PDF

Padrões Técnicos

Arquitetura distribuída com microsserviço de processamento em batch desacoplado via RabbitMQ/HTTP, isolando processamento pesado de I/O do servidor web PHP.

  • Processamento assíncrono de grandes volumes de dados (streaming sem sobrecarga de RAM)
  • Isolamento em contêineres Docker com orquestração simplificada
  • Módulos para formatação de planilhas Excel avançadas com formatação condicional
  • Conectores de streaming para bancos de dados MySQL e PostgreSQL
